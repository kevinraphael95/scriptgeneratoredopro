Structure des Dossiers EDOPro

Pour qu'EDOPro reconnaisse votre carte personnalisée, respectez strictement l'arborescence :

  • expansions/
  • ├── custom.cdb (Database SQL)
  • ├── script/
  • │ └── c10000001.lua (Script LUA)
  • └── pics/
  • └── 10000001.jpg (Image)

Paramètres des Fonctions (`e,tp,eg...`)

e : L'effet courant (`Effect` object)

tp : Triggering Player (0 ou 1)

eg : Event Group (Cartes liées au déclencheur)

ep : Event Player (Joueur ayant causé l'event)

ev : Event Value (ex: valeur de dégâts)

re : Reason Effect (Effet responsable)

chk : Check Pass (`0` = test légalité, `1` = exécution)

Types de Limitations (HOPT)

Soft OPT: `e:SetCountLimit(1)`

Une fois par tour par exemplaire sur le terrain.

Hard OPT (Use): `e:SetCountLimit(1, id)`

Vous ne pouvez utiliser cet effet de [Nom] qu'une fois par tour.

Hard OPT (Oath): `e:SetCountLimit(1, id, EFFECT_COUNT_CODE_OATH)`

Si l'activation est annulée, vous ne pouvez plus le réactiver.
