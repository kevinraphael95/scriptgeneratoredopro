Structure de base (cID.lua)

Chaque carte enregistre ses effets dans la fonction s.initial_effect(c).

local s, id = GetID()

function s.initial_effect(c)
  -- Enregistrement d'un effet
  local e1 = Effect.CreateEffect(c)
  e1:SetType(EFFECT_TYPE_IGNITION)
  e1:SetRange(LOCATION_MZONE)
  e1:SetCountLimit(1, id) -- Hard OPT
  e1:SetTarget(s.tg1)
  e1:SetOperation(s.op1)
  c:RegisterEffect(e1)
end

Archétypes & Cartes liées

Les propriétés de recherche ou de synergie se définissent via des listes d'IDs et de masques d'archétypes :

  • s.listed_series = { 0x8, 0x3008 } — Archétype(s) référencé(s).
  • s.listed_names = { 46986414 } — IDs spécifiques cités texte pour texte.
